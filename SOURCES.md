# Sources and attribution

Checked 2026-10-02. Links below are primary project/author sources. A cited layout
example is not a bundled asset or a promise of compatibility with every game build.

1. **ScriptHookVDotNet Enhanced — project repository and installation guidance.**
   https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced
   API v3 script loading and matching dependency instructions.
2. **Script Hook V — Alexander Blade.**
   https://www.dev-c.com/gtav/scripthookv/
   Native scripting loader; obtain a release compatible with the installed game.
3. **OpenRPF — Los Santos Multiplayer team, author description.**
   https://www.gta5-mods.com/tools/openrpf-openiv-asi-for-gta-v-enhanced
   Enhanced `mods` archive loading and Legacy/Gen9 resource compatibility caveat.
4. **Devel Sixteen — vehicle author's Enhanced add-on instructions.**
   https://www.gta5-mods.com/vehicles/devel-sixteen-add-on
   DLC-folder, `dlclist.xml` and spawn-name example used in ADDONS.md.
5. **Custom Trio Clothes — clothing author's Enhanced instructions.**
   https://www.gta5-mods.com/player/custom-trio-clothes
   `spPlayersClothes_Gen9` example, character-specific clothes and required archive tools.
6. **BMW M3 E46 GTR Engine Sound — KCMIR0, author installation instructions.**
   https://www.gta5-mods.com/vehicles/bmw-m3-e46-gtr-engine-sound-mod-add-on-fivem
   Single-player audio DLC registration and `audioNameHash` assignment. Older
   layout reference only; Enhanced compatibility of that download is not established.
7. **PolyForm Noncommercial 1.0.0 — official license.**
   https://polyformproject.org/licenses/noncommercial/1.0.0
   https://github.com/polyformproject/polyform-licenses/blob/1.0.0/PolyForm-Noncommercial-1.0.0.md
   The unchanged license is included in LICENSE.md. The upstream repository
   permits copying the license text: https://github.com/polyformproject/polyform-licenses
8. **Apache License 2.0 — Apache Software Foundation.**
   https://www.apache.org/licenses/LICENSE-2.0

   https://opensource.org/osd

10. **Native reference projects.**
    https://github.com/alloc8or/gta5-nativedb-data
